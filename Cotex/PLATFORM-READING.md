# Cotex 番茄 / 起点增强版

版本：1.1.3-platform.1，基于 BrokenHT/Cotex_DeskReader 的 1.1.2 源码。

## 使用

1. 启动 Cotex，按 Ctrl + K 打开搜索资料。
2. 切换到「番茄小说」或「起点中文网」。
3. 粘贴官方书籍详情页链接，点击搜索，再点「加入」。
4. 也可以点「登录 / 官方窗口」，在官网登录、完成验证，进入书籍详情或阅读页，点击窗口顶部「加入 Cotex」。从阅读页加入时会定位到该章节。
5. 遇到章节提示需要登录或订阅，点击「打开原站」完成操作，再回到 Cotex 点「重试」。

书籍和阅读位置保存在本机。账号登录保存在本机独立的平台会话里，官方网页不接触 Cotex 的本地文件接口。此版本没有手机 App 阅读进度同步。

## 已验证与限制

- 番茄：官方书库列表、详情链接导入、1496 章目录、首章正文和原站字体显示、更新目录保留位置与缓存，以及官方窗口选书导入已实测。
- 番茄官网关键词搜索在本次测试中返回空结果，程序会提示使用详情链接或官方窗口；不会把这个情况伪装成正常命中。
- 起点：官方窗口、独立登录会话、目录及正文适配、权限提示已实现。真实网站目前要求人工验证，账号登录后章节阅读尚未完成实测；不能保证每本书或所有 VIP 章节兼容。若页面不兼容，仍可在 Cotex 的官方窗口继续阅读。
- 只使用官方网页实际提供的内容及当前账号已有的阅读权限。购买和订阅仍由官方页面处理。
- 番茄部分内容使用专用字体，字体随已读章节保存；这类章节暂不支持复制或导出纯文本，可使用书库备份。
- 原有 TXT / EPUB 导入、书签和本地阅读功能保留。原版便携程序保留在安装包目录，可随时切换。

## 维护

新增平台配置、页面提取和官方窗口管理位于 electron/platform-config.cjs、electron/platform-extract.cjs、electron/platforms.cjs。平台改变网页结构时可能需要更新这些适配。

验证命令：

- npm test：原有与新增单元测试。
- npm run test:ui：原有桌面阅读交互和重启持久化。
- npm run test:platforms：本地页面样例验证目录、正文和权限判定。
- npm run test:platforms:live：联网验证番茄链接导入、字体和刷新。
- npm run test:platforms:flow：联网验证官方窗口加入及指定章节定位。

所有自动化测试使用独立的临时书库，不修改日常书库。
