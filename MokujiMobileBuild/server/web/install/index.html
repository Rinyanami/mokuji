安装到手机与平板

iPhone / iPad（推荐：免签名全屏独立应用，永不过期）

方案一（最省事，30 秒完成）：用 Safari 点击下方「下载 iPhone 全屏桌面图标」，再去系统「设置 → 已下载描述文件」点安装。桌面生成的「目次」图标会以无地址栏全屏 App 模式启动，内置离线章节缓存，且永久不会像自签 IPA 一样每 7 天掉签。

下载 iPhone 全屏桌面图标 免签名 WebClip

方案二（零描述文件）：先点页面底部「返回目次」，在 Safari 底部点「分享 → 添加到主屏幕」，同样享受全屏独立 App 与离线缓存体验。

iOS「快捷指令」一键抓书入库

在 iPhone「快捷指令」新建一条分享菜单指令：接收「Safari 网页或网址」→ 执行「打开网址」填入 http://你的目次地址/?sniff=[快捷指令输入]。在 Safari 看任何小说/轻小说/漫画时点分享即可一键嗅探进目次书架。

原生应用 · iOS 17 及以上（适合 AltStore / SideStore / TrollStore 用户）

如果你已在用 SideStore（自动后台续签）或巨魔商店，可在电脑下载未签名 IPA 安装。
