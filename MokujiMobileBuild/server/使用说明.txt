目次 Mokuji · 多端阅读、书架整理与摸鱼工作台 · 使用说明

一、Windows 桌面端（开箱即用，无需单独配置环境）
- 直接双击运行 Mokuji.exe（已整合正常书架与摸鱼工作区，不再需要多个分开的快捷方式）。
- 常用快捷键：
  • Ctrl + Shift + W：同一窗口内一键切换「我的书架」与「摸鱼工作区」
  • Ctrl + Alt + M：全局老板键（任何窗口焦点下瞬间隐藏 / 呼出目次窗口）
  • 空格 Space（在摸鱼工作区内）：瞬间切为伪装工作摘要与附件，并自动锁定回隐藏真名，再按一次回到阅读段落
  • Alt + V 或点击工作区「眼睛图标」：悬停看真名以外，可一键切换全目录/书名全显真名（支持搜索真实章节名，触屏/电脑均可单手操作）
  • F11：无边框全屏阅读；点右上角 × 最小化到右下角系统托盘（右键托盘可切工作区或彻底退出）
- 运行 Create-Desktop-Shortcut.cmd 可在桌面生成统一的「目次 Mokuji」快捷方式。

二、Bangumi 级自定义书架 & 双向联动
- 在「我的书架」可点击「自定义分类/评分/标签」自由增删改名门类、切换「Bangumi 标准 / 网文仙草」等 10 分制语义档位、管理常用 Tag、新建专题书单与批量整理。
- 在「个人主页」可绑定 Bangumi Access Token，实现阅读状态、评分、章/卷进度与私密收藏的双向同步。

三、书源搜索、漫画与万能网页嗅探
- 进入「阅读 → 书源与嗅探」已内置晋江、SF 轻小说、ESJ Zone、成为小说家吧、MangaDex 漫画、纵横、17K、维基文库与 6 套 Legado 规则模板；
- 找不到书源的网站，直接将书籍目录页、长文章页、漫画页或 .txt/.epub/.cbz 直链贴入「智能嗅探」即可抓入书架离线阅读。

四、iPhone / Android / 电纸书多端使用
- 在电脑端「手机连接」开启局域网访问后，iPhone Safari 扫码可安装「全屏免签名桌面图标 (.mobileconfig)」或「添加到主屏幕」，永久不掉签并支持 iOS 快捷指令（/?sniff=网址）一键抓书。
- Android 可下载安装页的 Mokuji-Android.apk 或直接使用 Chrome 安装 PWA。
- Kindle / 文石 / KOReader 可连接同一局域网下的 /opds（OPDS 1.2 自动封包 EPUB）或 /eink 墨水屏极简阅读网页。

五、云同步与备份
- 在「个人主页」支持七牛云 Kodo (S3) 与 NAS WebDAV 全量双向同步与无缝迁移，所有本地数据与书档保存在本目录下的 data 文件夹中，导出备份或直接复制 data 文件夹即可完整迁移。
